# Documents

This is the read-only document library. Files are discovered automatically from directories named `doc-<category-name>`.

To publish a document, upload the document and its sidecar metadata JSON. You do not need to edit this page or any HTML.

Example:

```text
doc-openai-deep-research/
├── research-note.md
├── research-note.md.json
├── paper.tex
└── paper.tex.json
```

Markdown (`.md`, `.markdown`), LaTeX (`.tex`), and DOCX (`.docx`) open inside the portfolio reader. PDF, text/data files, images, audio/video, and other formats open as the original file in a new tab.

Use the category jump links, tag filter, search, and sort controls below to browse the library.
